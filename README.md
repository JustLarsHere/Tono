# Tono - A Music Player
Tono is an extension based music player for Desktop.

### Disclaimer
> [!NOTE]
> The developers of this software are not affiliated with any third party content providers and are not liable for any misuse.
>
> This software only features a built-in offline local music provider, as it functions merely as a framework for playing music and is not intended for piracy.
> Users add third party content providers at their own risk and discretion


### Platforms
Tono is only focused towards desktop applications (Linux, Windows, Macos), therefore a version for Android or iPhone does not exist and will not be made.
